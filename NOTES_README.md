📝 Note Keeper

A simple and responsive note-taking web application built with HTML, CSS and JavaScript.

🌐 Live Demo

"Open Note Keeper" (https://paswan930.github.io/mywebsite/notes.html)

✨ Features

- 📝 Create new notes
- 🗑️ Delete notes
- 💾 Save notes using browser Local Storage
- 📱 Responsive design
- 🎨 Clean and simple interface
- ⚡ Fast and easy to use

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

💾 Data Storage

Notes are stored in the browser using Local Storage, so they remain available when the page is reopened on the same browser.

📱 Responsive Design

The application is designed to work across:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Desktop computers

🎯 Purpose

This project was created as part of my web-development learning journey to practice JavaScript, DOM manipulation and browser Local Storage.
