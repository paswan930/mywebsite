🌦️ Weather App

A responsive weather application built with HTML, CSS, JavaScript and a Weather API.

🌐 Live Demo

"Open Weather App" (https://paswan930.github.io/mywebsite/weather.html)

✨ Features

- 🔍 Search weather by city
- 🌡️ Display current temperature
- 💨 Show wind speed
- 🕐 Display local time
- 📱 Responsive design
- 🎨 Clean and user-friendly interface
- 🌐 API-based weather data

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Weather API

☁️ How It Works

1. Enter the name of a city.
2. The app requests weather data from the API.
3. Current weather information is displayed.
4. The interface adapts to mobile and desktop screens.

📱 Responsive Design

The application is designed to work smoothly on:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Desktop computers

🎯 Purpose

This project was created as part of my web-development learning journey to practice JavaScript, API integration, asynchronous data handling and responsive web design.
