✅ To-Do App

A simple and responsive task management web application built with HTML, CSS and JavaScript.

🌐 Live Demo

"Open To-Do App" (https://paswan930.github.io/mywebsite/todo.html)

✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks in the browser
- 📱 Responsive design
- 🎨 Clean and simple interface
- ⚡ Interactive JavaScript functionality

🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

📋 How It Works

1. Enter a task.
2. Add the task to your list.
3. Mark it as completed when finished.
4. Delete tasks when they are no longer needed.
5. Tasks can remain saved in the browser.

📱 Responsive Design

The application is designed to work smoothly on:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Desktop computers

🎯 Purpose

This project was created as part of my web-development learning journey to practice JavaScript, DOM manipulation, event handling and browser Local Storage.
