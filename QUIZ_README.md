❓ Quiz App

An interactive and responsive quiz application built with HTML, CSS and JavaScript.

🌐 Live Demo

"Open Quiz App" (https://paswan930.github.io/mywebsite/quiz.html)

✨ Features

- ❓ Multiple-choice questions
- ✅ Instant answer feedback
- 📊 Score tracking
- 🔄 Restart quiz option
- 📱 Responsive design
- 🎨 Clean and modern interface
- ⚡ Interactive JavaScript functionality

🛠️ Technologies

- HTML5
- CSS3
- JavaScript

🎮 How It Works

1. Open the Quiz App.
2. Read the question and select an answer.
3. Get feedback after answering.
4. Continue through the questions.
5. Check your final score.
6. Restart the quiz to try again.

📱 Responsive Design

The quiz is designed to work smoothly on:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Desktop computers

🎯 Purpose

This project was created as part of my web-development learning journey to practice JavaScript logic, user interaction, DOM manipulation and responsive web design.
